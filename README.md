## 🎮 ゲームシステムと拡大再生産ループ

### 1. 素粒子の射出とハドロン合成 (素粒子物理)
- **アップクォーク ($u$: 電荷 $+2/3$)** と **ダウンクォーク ($d$: 電荷 $-1/3$)**、**電子 ($e^-$: 電荷 $-1$)** を射出します。
- チャンバー内でクォーク同士が近づくと「強い相互作用（グルーオン）」が働き、結合します。
  - **陽子 (Proton, $p$)**: $u + u + d$ (電荷 $+1$)
  - **中性子 (Neutron, $n$)**: $u + d + d$ (電荷 $0$)

### 2. 水素同位体の組み立て (核物理・燃料製造)
- 陽子・中性子・電子を結合させて燃料同位体を作ります。
  - **軽水素 ($^1\text{H}$)**: $1p + 1e^-$
  - **重水素 ($^2\text{H}$ / $\text{D}$)**: $1p + 1n + 1e^-$ (海水中から無尽蔵に得られる基本燃料)
  - **三重水素 ($^3\text{H}$ / $\text{T}$)**: $1p + 2n + 1e^-$ (半減期12.3年。天然には希少な超高効率燃料)

### 3. トカマク核融合反応 (プラズマ物理)
- 重水素と三重水素をトカマク炉心へ注入。
- 「⚡ 磁気パルス圧縮点火」でプラズマを加熱・圧縮し、D-T核融合反応を発生させます。
  $$^2\text{H} + ^3\text{H} \longrightarrow \,^4\text{He}\,(3.5\text{ MeV}) + n\,(14.1\text{ MeV}) + 17.59\text{ MeV}$$
- **$3.5\text{ MeV}$ のアルファ粒子 ($^4\text{He}$)** は磁場に捕捉され、プラズマを自己加熱（温度上昇）。
- **$14.1\text{ MeV}$ の高速中性子 ($n$)** は磁場をすり抜け、炉壁へエネルギーを運びます。

### 4. リチウム増殖ブランケットと拡大再生産 (自律増殖サイクル)
- 炉壁に配置した「増殖ブランケット」が高速中性子を捕獲：
  $$^6\text{Li} + n \longrightarrow \,^4\text{He} + ^3\text{H} + 4.78\text{ MeV}$$
- **消費した以上の三重水素が自動増殖**（トリチウム増殖比 TBR > 1.05）！
- 生み出された莫大なエネルギーで：
  1. クォーク真空抽出機・熱陰極電子銃（素粒子の自動生成）
  2. 自動ハドロン結合炉・自動同位体結晶機（陽子・中性子・重水素の自動組立）
  3. 高温超伝導(HTS)マグネット・中性粒子ビーム入射(NBI)・ペレット連続注入機（ローソン積 $n \tau T$ の極大化）
  4. 液体リチウム流動ダイバータ & MHD熱回収発電機
  5. 海水リチウム吸着電解プラント・レーザー同位体分離カスケード・小惑星帯リチウム採掘船団（リチウム-6の爆発的大量自動供給）
  6. ギルドラー・サルファイド(GS)式重水プラント・極低温液体水素蒸留塔・海洋直接触媒抽出メガフロート群（海水からの重水素-2爆発的大量自動抽出）
- 施設を増強することで、エネルギーと資源の生産規模が指数関数的に拡大していきます。

## 📖 核融合促進・Q値極大化 攻略手順書 (Strategy Guide)

ゲーム内ヘッダーの「**📖 攻略手順書**」ボタン、または炉心パネルのリンクからいつでも閲覧できます。

### 1. 5大フェーズによる最短攻略ロードマップ
- **【Phase 1】初動点火 (0 〜 100 MeV)**:
  - $u, d, e^-$ を射出し、$uud \to p$、$udd \to n$ を合成。
  - $1p + 1n + 1e^- \to \text{D}$（重水素）、$1p + 2n + 1e^- \to \text{T}$（三重水素）を各1個以上作り、炉心へ注入して「⚡ 磁気パルス圧縮点火」！
  - 初の核融合で $17.6\text{ MeV}$ を獲得。
- **【Phase 2】自動化と自律増殖ループ (100 〜 10,000 MeV)**:
  - クォーク抽出機・電子銃を建設し素粒子を自動化。「全合成」ボタンで燃料を一括生成。
  - ★**最重要**: 「**リチウム増殖ブランケット**」を建設！
    $14.1\text{ MeV}$ 高速中性子で $^6\text{Li} + n \to ^4\text{He} + ^3\text{H} + 4.8\text{ MeV}$ を起こし、**三重水素を自動増殖（TBR > 1.15）**させて燃料切れを克服。
- **【Phase 3】燃料の定常注入と連続燃焼 (10,000 〜 100,000 MeV)**:
  - 「☑ 自動連続注入」をONにし、DとTを常時供給。
  - **海水重水素大量生産設備（GS式重水プラント、極低温蒸留塔、海洋メガフロート群）** を建設し、クォーク・核子の合成工程を完全バイパスして毎秒数百〜数千の重水素($^2\text{H}$)を直接海から汲み上げる。
  - **リチウム大量生産設備（海水プラント、レーザー濃縮、小惑星採掘船団）** を建設して毎秒数百個のリチウム-6を自動供給し、手動補充の手間を完全に解消。
  - 一時的な補充には「+100 Li」「+1,000 Li」一括購入ボタンを活用。
- **【Phase 4】ローソン3重積の極大化 ($Q \ge 1.0$ 臨界プラズマ突破)**:
  - **超伝導マグネット(HTS)**: 閉じ込め時間 $\tau_E$ を延長し冷却を防止。
  - **ペレット連続注入器**: 密度 $n$ を極大化し衝突頻度を倍増。
  - **NBI加熱装置**: プラズマ温度 $T$ を断面積ピーク（10 keV / 1億度以上）へ到達させる。
- **【Phase 5】自律燃焼プラズマとQ値10超え ($Q \ge 5 \to Q \ge 10$)**:
  - 研究「**自己加熱燃焼プラズマ自律制御**」を習得 $\to$ アルファ線($^4\text{He}, 3.5\text{ MeV}$)の自己加熱を活用し、外部加熱入力 $P_{\text{heat}}$ を大幅削減（Q値が跳ね上がります）。
  - 研究「**量子トンネル確率共鳴励起**」（反応率 $+50\%$）や「**準対称ステラレーター立体磁場配位**」で究極の定常燃焼を達成！

### 2. Q値を爆発的に上げる「3大変数」
$$Q = \frac{P_{\text{fusion}}}{P_{\text{heat}}}$$
- **燃料比率**: 重水素(D)と三重水素(T)が常に $1:1$ であること（どちらか一方だけでは反応しない）。
- **中心温度 $T$**: $10\text{ keV}$（約1億1600万℃）以上を維持（連続燃焼によるアルファ線自己加熱が決め手）。
- **閉じ込め時間 $\tau_E$**: 超伝導マグネットを増設して熱損失を極小化。
- **分母 $P_{\text{heat}}$ の圧縮**: 研究「自己加熱燃焼プラズマ自律制御」を習得して外部加熱への依存を断ち切る。
